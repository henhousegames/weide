# Weide

Static snapshot of **Weide**, the in-world social network of the *animal influencers* video series
(human-sized farm animals doing normal creator content). All characters, posts and comments are fictional;
the videos are AI-generated.

Live: https://henhousegames.github.io/weide/

Generated with `weide.py export-static` (JSON per API view + web-sized media); reactions only count in your browser.
